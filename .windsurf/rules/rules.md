# Windsurf Rules for datarust

## Project Guidelines
- Workspace crates: `datarust` (classical ML) and `datarust-profile` (EDA and quality checks).
- Numerical linear algebra is implemented in pure safe Rust.
- Follow scikit-learn estimator interface patterns (`fit`, `predict`, `transform`).
- Official documentation and endpoints: `https://datarust.dev/docs/`, `https://datarust.dev/mcp`.
